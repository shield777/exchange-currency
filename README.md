# 환율계산기

여행 가는 나라의 돈을 원화(KRW)와 서로 바꿔 보는 여행용 웹앱입니다.
상단에서 나라를 고르면(베트남·일본·태국·중국·대만·홍콩·필리핀·싱가포르·말레이시아·인도네시아·미국·유럽·영국·호주·캐나다) 그 나라 기준으로 바뀌고, 고른 나라는 앱을 다시 켜도 기억됩니다.
아이폰·아이패드 Safari에서 "홈 화면에 추가"하면 일반 앱처럼 아이콘으로 실행됩니다.

## 기능

- 큰 숫자 키패드와 `000` 키
- 나라별 지폐 버튼(예: 베트남 +10k ~ +500k)으로 금액 빠르게 더하기
- 함께 볼 통화 최대 3개 선택 (기본: 달러·엔·위안)
- 결과 줄을 누르면 그 통화로 입력 전환 (예: 원화 예산 → 동으로 얼마?)
- 나눠 내기 (1인당 원화)
- 나라별 지폐 환산표와 현지 팁 (암산 공식, 가격표 읽는 법, 팁 문화 등)
- 환율 직접 입력, 현지에서 달러를 바꾼 환율 계산, 카드 수수료 % 반영

## 환율은 어디서 오나

- 인터넷이 되면 [open.er-api.com](https://www.exchangerate-api.com/docs/free)에서 받아오고,
  실패하면 [currency-api](https://github.com/fawazahmed0/exchange-api)로 다시 시도합니다.
- 하루 1번 갱신되는 **시장 중간 환율**입니다. 실제 환전소·카드 환율과는 1~3% 차이가 날 수 있습니다.
- 받은 환율은 기기에 저장돼서 비행기 안이나 데이터가 없을 때도 계산됩니다.
- 한 번도 받아오지 못했으면 앱에 들어 있는 기본값(2026년 9월 근사치)을 쓰고, 상단에 노란색으로 표시됩니다.

## 설치 (가족 모두)

1. 이 폴더를 HTTPS 주소로 올립니다 (예: GitHub Pages, 공개 저장소 필요).
2. 아이폰 Safari에서 그 주소를 엽니다.
3. 공유 버튼 → **홈 화면에 추가**.
4. 출국 전에 한 번 열어서 상단에 날짜가 초록색으로 뜨는지 확인합니다 (환율 저장 완료).

설정(직접 입력한 환율, 수수료)은 기기마다 따로 저장됩니다.
