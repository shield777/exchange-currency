# 환율계산기

여행 가는 나라의 돈을 원화(KRW)와 서로 바꿔 보는 여행용 웹앱입니다.
상단에서 나라를 고르면(베트남·일본·태국·중국·대만·홍콩·필리핀·싱가포르·말레이시아·인도네시아·미국·유럽·영국·호주·캐나다) 그 나라 기준으로 바뀌고, 고른 나라는 앱을 다시 켜도 기억됩니다.
아이폰·아이패드 Safari에서 "홈 화면에 추가"하면 일반 앱처럼 아이콘으로 실행됩니다.

## 기능

- 큰 숫자 키패드와 `000` 키
- 나라별 지폐 버튼(예: 베트남 +10k ~ +500k)으로 금액 빠르게 더하기
- 함께 볼 통화 최대 3개 선택 (기본: 달러)
- 금액은 소수점 둘째 자리까지 표시 (예: 5,494.51원). 동·엔·대만달러·루피아는 정수로 표시
- 결과 줄을 누르면 그 통화로 입력 전환 (예: 원화 예산 → 동으로 얼마?)
- 사칙연산 (＋ − × ÷): 예) 120,000 + 50,000 × 2 를 바로 원화로 환산
- 나라별 지폐 환산표와 현지 팁 (암산 공식, 가격표 읽는 법, 팁 문화 등)
- 환율 직접 입력, 현지에서 달러를 바꾼 환율 계산, 카드 수수료 % 반영

## 환율은 어디서 오나

- 앱을 열어둔 동안 1시간마다 새로 받아옵니다 (다시 열 때도 1시간이 지났으면 바로 받아옴).
- 출처는 Coinbase 공개 환율 → [open.er-api.com](https://www.exchangerate-api.com/docs/free) → [currency-api](https://github.com/fawazahmed0/exchange-api) 순서로 시도합니다.
  뒤의 두 곳은 하루 1번만 바뀝니다.
- **시장 중간 환율**입니다. 실제 환전소·카드 환율과는 1~3% 차이가 날 수 있습니다.
- 받은 환율은 기기에 저장돼서 비행기 안이나 데이터가 없을 때도 계산됩니다.
- 한 번도 받아오지 못했으면 앱에 들어 있는 기본값(2026년 9월 근사치)을 쓰고, 상단에 노란색으로 표시됩니다.

## 설치 (가족 모두)

1. 아이폰 Safari에서 https://shield777.github.io/exchange-currency/ 를 엽니다.
2. 공유 버튼 → **홈 화면에 추가**.
3. 출국 전에 한 번 열어서 상단에 날짜가 초록색으로 뜨는지 확인합니다 (환율 저장 완료).

설정(직접 입력한 환율, 수수료)은 기기마다 따로 저장됩니다.
